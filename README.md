# Moshta3el — Telegram Channel Manager

أداة Python تعمل من الطرفية لإدارة قناة تيليجرام عبر **Telegram Bot API**، مع إبقاء التحكم بيد مالك القناة وصلاحيات البوت.

## الميزات

- عرض معلومات القناة.
- تغيير اسم القناة ووصفها وصورتها.
- نشر رسالة نصية أو صورة مع وصف.
- تعديل رسالة نصية أو حذف منشور باستخدام `Message ID`.
- تثبيت منشور وإلغاء تثبيته.
- عرض مشرفي القناة.
- ترقية مستخدم إلى مشرف مع اختيار الصلاحيات، أو خفض صلاحيات مشرف.
- تغيير القناة المستهدفة من داخل الأداة.

## التثبيت

Python 3.10 أو أحدث مطلوب.

```bash
python -m pip install -r requirements.txt
python main.py
```

على Windows يمكن تشغيل الملف من CMD أو PowerShell داخل مجلد المشروع.

## إعداد تيليجرام

1. أنشئ بوتًا أو اختر بوتك عبر `@BotFather` وخذ التوكن.
2. أضف البوت إلى القناة مشرفًا.
3. امنحه فقط الحقوق التي تحتاجها، مثل نشر الرسائل وتعديلها وحذفها وتغيير معلومات القناة وإدارة المشرفين.
4. شغّل الأداة وأدخل التوكن ومعرّف القناة، مثل `@your_channel` أو رقم `chat_id` المناسب.

يمكن أيضًا ضبط متغير البيئة `TELEGRAM_BOT_TOKEN` قبل التشغيل بدل إدخال التوكن يدويًا. لا تشارك التوكن مع أحد ولا تضعه في ملفات عامة.

## حدود مهمة في Telegram

- الأداة لا تتجاوز صلاحيات تيليجرام؛ إذا لم يمتلك البوت الحق اللازم فستظهر رسالة الخطأ من API.
- تغيير اسم القناة ووصفها وصورتها، والنشر والتعديل والحذف وإدارة المشرفين، يعتمد على صلاحيات البوت الفعلية.
- **لا تسمح Telegram Bot API بحذف القناة نفسها أو نقل ملكيتها**؛ يجب أن ينفذ مالك القناة إجراءات الملكية أو حذف القناة من تطبيق تيليجرام.
- تعديل رسالة يتطلب أن تكون الرسالة قابلة للتعديل وأن يسمح تيليجرام بذلك. حذف الرسائل وتثبيتها يخضعان كذلك لقيود API.
- ترقية أو خفض صلاحيات مشرف لا يمكن أن يمنح البوت صلاحيات أعلى من الحقوق التي يملكها هو. بعض القيود الإضافية قد يفرضها تيليجرام على المشرفين.
- الأداة لا تطلب كلمة مرور حسابك أو كود تسجيل الدخول أو ملف جلسة حساب شخصي؛ تستخدم توكن البوت فقط.
